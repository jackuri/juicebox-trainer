Play fair & safety

What JuiceBox Trainer works with, what it never does, and how to check that your download is the real one.

Which games

PC games without anti-cheat: single-player games, co-op with friends, and online games that have no anti-cheat. Games that run in a web page work too.

JuiceBox Trainer checks every game before it attaches, and again every few seconds. If a game's anti-cheat is running, it refuses, and that can't be switched off. It never switches anti-cheat off or gets around it. Some games have an official way to play without their anti-cheat; started that way, they're fine.

Cheats are fine alone, with friends, or in games without anti-cheat. Please don't use them to spoil other players' fun in public, competitive or ranked matches: other players can report you, and games can ban accounts. Web cheats aren't listed for competitive games or games with items you can trade for real money.

What it changes on your PC

  • Only the running game. Cheats change numbers in the game while it runs, and a few checked bytes of its code. Turning a cheat off, closing the game or closing JuiceBox Trainer puts everything back. If JuiceBox Trainer ever crashes, it undoes leftover changes the next time it starts.
  • Your saves are backed up when you attach to a game, when it starts and when it closes, so a save that goes wrong can be put back.
  • Packs have no programs inside. A pack is a list of cheats. JuiceBox Trainer checks every pack before using it, and shows you what's inside before you install one.
  • Cheat Engine table scripts are never run. They're only read, and the common kinds are redone JuiceBox Trainer's own, checked way.
  • The AI helper can only use JuiceBox Trainer's guarded tools. It can't run programs or read your files. It refuses games with anti-cheat, its test changes are undone when it stops, and every step is written to a log on your PC. You set the most it may spend.
  • It never changes your network settings.

"Windows protected your PC" and antivirus warnings

Trainers change other programs' memory, so some antivirus programs flag them. JuiceBox Trainer doesn't hide what it does: its source code is public, and it never packs or scrambles itself to slip past antivirus.

It isn't code-signed yet (that costs money and is planned), so Windows may say "Windows protected your PC" the first time. Click More info, then Run anyway, but only for the file from the releases page.

To check your download is the real one: every release has a SHA256SUMS.txt file. Open PowerShell in your Downloads folder and type:

Get-FileHash .\JuiceBoxTrainer_{{VERSION}}_x64-setup.exe

The long number it shows must match the one in SHA256SUMS.txt for that file.

What it sends, and where

  • Nothing about you, and no analytics. Problems it notes for the Help page stay on your PC.
  • It downloads the community list and checks for updates from GitHub.
  • Sharing, rating and the daily check-in go to GitHub with your GitHub name, and only after you sign in and choose to.
  • The AI helper talks to the AI you picked (Claude, or a free AI on your own PC). With Let the helper look at the game window on, pictures of that window go to that AI too, and aren't saved.
  • Searching for a cheat table opens your browser with only the game's name.

This website has no cookies and no analytics. The community pages read the community list from GitHub in your browser.
